### [🗓️ Event Calendar Engine — Hand-Built Data Structures](https://github.com/ahmadmuzii/DSA-Project)
**C++17 · CMake · cpp-httplib REST API · React 18 · Doctest (161 assertions)**

Calendar system where **every data structure is written from scratch** — no `std::map`, no `std::priority_queue`.

- ✅ **AVL tree** (self-balancing BST) — date queries in O(log n)
- ✅ **Hash table** with chaining (31 prime buckets, djb2 hash) — O(1) ID lookup
- ✅ **Indexed min-heap** — "what's next?" in O(log n) + O(log n) delete-by-ID
- ✅ **12 REST endpoints** — full CRUD, date range queries, conflict detection, CSV save/load, TXT export
- ✅ **Memory-safe:** `std::unique_ptr` — no manual `new`/`delete`
- ✅ **Robust conflict detection:** overlapping events highlighted in UI
- ✅ **Production-style server:** JSON/form bodies, 400/404/409 status codes, CORS, graceful shutdown
